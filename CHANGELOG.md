# Changelog

## 2.0.0
- **Branches / chains:** owner account with one admin + cashier account per branch; every branch admin sees only their branch; owner dashboard with per-branch KPIs. Branch limit comes from the subscription plan.
- **Business templates:** one-click service catalogs for 9 print/gift sectors (copy center, digital, large format, offset, packaging, apparel, gifts, stickers, general).
- **Cashier:** edit invoices (admin-controlled), manual + fixed finishing services, payments page (partial / per-invoice, timestamped), old balances, automatic customer registry with VIP tiers, quick-sale counter without invoices.
- **Admin:** full invoice designer (sizes, fonts, colors, labels, logo, live preview), invoice editor, finishing services, loyalty tiers, cashier permissions.
- **Platform:** Arabic / English UI, CSRF protection, popups instead of browser dialogs, guided tours, card (ID) login removed, random initial super-admin password, pytest suite.
